# JSON 提示词字段规范

Nano Banana 结构化提示词的完整 Schema 与逐字段填写要领。生成路径 A 前必读。

## 与生图模型的兼容性

本 Schema 产出的 JSON 提示词**同时兼容 Nano Banana 与 GPT-Image 两个模型家族**（2026-10-14 实测：同一份 JSON 分别经 `service-inference/gemini-nano-banana-2.1` 与 `apiz/gpt-image-2.5-flare` 出图均获正确消费）。JSON 原文直接作为 prompt 传给生图接口，无需转换；出图操作见 `image-generation.md`。

## 完整结构

```json
{
  "风格模式": "string",
  "画面气质": "string",
  "场景": {
    "环境": {
      "地点设定": "string",
      "光线": "string",
      "天气氛围": "string"
    },
    "主体": {
      "整体描述": "string",
      "外形特征": {
        "身材": "string",
        "面部": "string",
        "头发": "string",
        "眼睛": "string"
      },
      "表情与动作": {
        "情绪": "string",
        "动作": "string"
      },
      "服装": {
        "穿着": "string",
        "细节": "string"
      },
      "配饰": "string"
    },
    "背景": {
      "描述": "string",
      "景深": "string"
    }
  },
  "相机": {
    "机位角度": "string",
    "构图": "string",
    "镜头特性": "string",
    "传感器画质": "string"
  },
  "审美控制": {
    "呈现意图": "string",
    "材质真实度": ["string", "string", "string"],
    "色彩风格": {
      "整体色调": "string",
      "对比度": "string",
      "特殊效果": "string"
    }
  }
}
```

## 逐字段填写要领

| 字段 | 要点 |
|---|---|
| 风格模式 | 顶层画风定调，多个修饰词用逗号分隔，如「高保真二次元插画, 官方立绘风格, 赛璐璐上色」 |
| 画面气质 | 情绪/氛围关键词，逗号分隔，如「清透, 治愈, 空灵, 极致可爱, 梦幻」 |
| 场景.环境.地点设定 | 具体地点 + 风格化特征，越具体越好（如「蔚蓝档案风格的木质海边车站」） |
| 场景.环境.光线 | 用专业布光术语：高调摄影（High-key）、丁达尔效应、轮廓光（Rim Light）、散射光等 |
| 场景.环境.天气氛围 | 季节 + 时间 + 空气感，带通感描写（「空气中充满透明感」） |
| 场景.主体.整体描述 | 角色/主体的身份与类别；IP 角色附原名（如「小鸟游星野（Takanashi Hoshino）」） |
| 场景.主体.外形特征.身材/面部/头发/眼睛 | 四个固定子字段逐项刻画；抓标志性特征（异色瞳、光环、呆毛） |
| 场景.主体.表情与动作.情绪 | 情绪词，可叠加层次（「慵懒中带着楚楚动人」） |
| 场景.主体.表情与动作.动作 | 完整动作链，写清肢体分工与互动对象，一句讲完 |
| 场景.主体.服装.穿着 | 配色与形制；有参考图时写「严格参考输入图片的…」 |
| 场景.主体.服装.细节 | 材质 + 装饰细节（丝绸质感宽袖、腰封、飘动丝带、绳结） |
| 场景.主体.配饰 | 发饰、手持物、漂浮物等点缀 |
| 场景.背景.描述 | 背景内容 + 干净度要求（「画面极其干净」） |
| 场景.背景.景深 | 虚化强度 + 目的（让背景成为「清新的衬托」） |
| 相机.机位角度 | 微微仰视/平视/侧面平视等 |
| 相机.构图 | 景别（全身中景等）+ 取舍意图（「完整显示脚部」） |
| 相机.镜头特性 | 虚拟焦段：35mm / 50mm / 85mm 人像 |
| 相机.传感器画质 | 8K、矢量级清晰度、无噪点等画质声明 |
| 审美控制.呈现意图 | 成品定位（顶级二次元游戏CG、Pixiv高赞插画、壁纸风格） |
| 审美控制.材质真实度 | **数组**（不是字符串），3 条左右：皮肤/头发/布料分述 |
| 审美控制.色彩风格.整体色调 | 主色 + 点缀色 + 明度对比度倾向 |
| 审美控制.色彩风格.对比度 | 明暗过渡风格；二次元常写「拒绝油腻厚涂感，保持通透」 |
| 审美控制.色彩风格.特殊效果 | 粒子、发光线条、花瓣、尘埃微粒等 |

## 类型红线

- 「材质真实度」**必须是字符串数组**，其余字段均为字符串。
- 键名必须与 Schema 完全一致（中文键名勿改动、勿翻译）。
- 场景/主体等嵌套层级不可拍平。

## 非人物主体调整

用户要画风景、物品、动物等非人物主体时：

- 「外形特征」子字段按对象改写（如动物写毛色/体型/品种特征；风景可整体弱化，将「主体」用于核心景物）。
- 「服装」可改为表面材质/覆着物描述，或整体省略该子对象时把信息并入「整体描述」。
- 其余字段（环境、相机、审美控制）规则不变。

## 可选负向字段（扩展）

项目词库中沉淀了负向控制词，生成强力排异的画面时可作为扩展字段附加在 JSON 顶层（非 Schema 必需，酌情使用）：

- `禁止元素`：写实风格、真人照片、3D渲染、恐怖谷效应、崩坏的脸、错误的瞳色、多余的手指、扭曲的肢体、水印、签名、文字等。
- `禁止风格`：低分辨率、模糊、噪点、胶片颗粒、过曝、欠曝、强对比度、过度HDR、色彩失真、JPEG压缩痕迹等。
